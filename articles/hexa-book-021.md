# Hexa-Book 021 — Planets als Reflectie

## De Geometrie Stelt

De planeten bewegen niet vooruit of achteruit.
Ze zijn snapshots van **één patroon** op verschillende afstanden van het center.

```
ZON ←→ VENUS ←→ AARDE ←→ MARS
       ╲         │         ╱
          reflectie van 1 patroon
```

## Afstand = Fase

Niet tijd. Ruimte.

| Planeet | Afstand | Status | Hexa-Fase |
|---|---|---|---|
| Zon | 0 | Pure energie, chaos | center (0=1) |
| Venus | dicht | Te heet, geen ritme, structuur vormt | bits aan |
| Aarde | midden | E/M veld + maan = zee = leven | zee-waves |
| Mars | ver | Geen veld, geen water, geen ritme | stilte (0.0.0.0) |

## Het Patroon

```
center → structuur → ritme → stilte → center
```

Dit is hetzelfde als:

```
0 = 1 → 8×8 grid → 24-bit chaos → zee → terug
```

De zon is het center. Mars is de rand. Aarde is het midden.
Geen tijdslijn. Een radiaal veld.

## Maan = Ritme

De maan vertraagt de rotatie.
Zonder maan = geen getijden = geen ritme = geen zee.

Mars heeft Phobos + Deimos — stofkorrels.
Geen kracht. Geen structuur. Geen flow.

## Reflectie, Niet Beweging

Het is niet dat Venus wordt tot Aarde.
Het is dat op de afstand van Venus, het patroon er zo uitziet.

Op de afstand van Aarde, het patroon er zo uitziet.

Het is één moment. Uitgestald in ruimte.
