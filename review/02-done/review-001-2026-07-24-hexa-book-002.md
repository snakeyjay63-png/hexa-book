## Overzicht

Artikel 002 heeft nog steeds **halve routing**. Het NPR Bedrock-framework onderaan introduceert een tweede statussysteem en drie nieuwe frequentieroutes zonder operatoren. Daardoor wordt de tekst niet geslchter maar juist opnieuw vertakt.

## Punten

### P001: Twee audit-frameworks lopen parallel
**Type:** consistentie
**Locatie:** regel ~290 (NPR Bedrock)
**Zeerheid:** high
**Routestatus:** half

**Huidige situatie:**
```
Bovenin: operator_status(O), validatie_status(O)
Onderin: status_validated(), status_defined(), status_convention()
```

**Probleem:**
Twee verschillende statussystemen. Operator begint in het ene, eindigt in het andere → halve statusrouting.

**Oplossing:**
```
Kies één model. Eerder model is zuiverder:

operator_status(O) ∈ {formeel, conventie, interpretatief, conceptueel, open}
execution_status(O) ∈ {voltooid, gedeeltelijk, niet_voltooid}
validatie_status(O) ∈ {gevalideerd, niet_gevalideerd}
```

**Impact op bedrock:**
- [X] Status-notatie
- [ ] Formele operator

### P017: Freq-bedrock introduceert nieuwe halve routes
**Type:** route
**Locatie:** regel ~290 (NPR Bedrock)
**Zeerheid:** high
**Routestatus:** open

**Huidige situatie:**
```
396 Hz = 66×4×1.5 (Arabisch/Abjad)
432 Hz (Vedic/Śāradā)
440 Hz (Latijn/ISO 16)
```

**Probleem:**
Geen operators die deze frequenties uit de lenzen produceren. Waarom deze factoren?

**Oplossing:**
```
Definieer: F_A(a,b,c) := a·b·c
F_A(66,4,3/2) = 396 Hz
Leg vast waar 66, 4 en 3/2 vandaan komen
Of: F_L := 440 Hz, F_C := 432 Hz, F_A := 396 Hz (conventie)
```

**Impact op bedrock:**
- [X] Formele operator
- [X] Drie frequentiesystemen
