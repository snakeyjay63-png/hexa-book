## De Terminal (CPU)

```
┌─────────────────────────────────────┐
│  1980 TERMINAL                      │
│                                     │
│  command: slow-build                │
│  command: space=wide                │
│                                     │
│  → CPU: lange spanningsbogen,       │
│    zachte kick, diepe groove        │
└──────────────────┬──────────────────┘
                   │ verbinding
                   ▼
┌─────────────────────────────────────┐
│  SYNTHS (veld)                      │
│                                     │
│  pad   → horizontaal → atmosfeer    │
│  pluck → punt → melodie             │
│                                     │
│  → GPU: wijde, ademende ruimte      │
└─────────────────────────────────────┘
```

---

## Synth Geometrie

| Synth | Geometrie | Vertraging | Uiting |
|---------|------------|------------|------------|
| pad | horizontaal | 500ms | zwevend |
| pluck | punt | 250ms | helder |
| bass | lijn | 125ms | diep |

---

## Progressive Psy = Interface-Taal

```
Progressive Psy zegt:
  "build" → pad doet horizontaal
  "space" → pluck doet punt
  "glide" → bass doet lijn
```
